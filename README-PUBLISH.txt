WHAT THIS VERSION ADDS
- Public shareable website card
- Add to Home Screen support (PWA)
- iPhone/Android-friendly mobile layout
- Real Save Contact (.vcf)
- Call, Text, Email, Website, Listings/Portfolio, Booking, Instagram, LinkedIn
- Native phone Share button
- QR code automatically points to the live URL
- Offline caching after first visit
- Separate setup editor (editor.html)
- profile.json controls the card content

QUICK CUSTOMIZATION
1. Open editor.html.
2. Fill in the buyer's details.
3. Click GENERATE profile.json.
4. Replace the sample profile.json in this folder with the downloaded one.
5. Publish this entire folder.

CLOUDFLARE PAGES
1. Create a new Pages project.
2. Upload this folder / deploy it as a static site.
3. No build command is required.
4. The output directory is the project root.
5. Cloudflare gives a public URL. A custom domain can be attached later.

GITHUB PAGES
1. Put all files in the root of a repository.
2. In repository Settings > Pages, deploy from the main branch/root.
3. GitHub gives the public Pages URL.

IMPORTANT
The QR code uses the current live page URL, so after publishing it automatically points to the real card.
On iPhone: open the live card in Safari > Share > Add to Home Screen.
On Android: Chrome may show ADD CARD TO HOME SCREEN, or use browser menu > Add to Home screen.
